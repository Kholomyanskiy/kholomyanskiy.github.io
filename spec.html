1.0 // PROBLEM

The project has been 'almost working' for a month

Familiar story: you described your idea to Claude Code or Cursor, got a working prototype in an evening, felt great. Two weeks later you're spending 4 hours a day fixing what worked yesterday. Every fix breaks something else.

$ fix: payment button
> report export broke
$ fix: report export
> payment button broke

The cause is almost always the same. The project has no specification. For every task, the agent re-guesses what you meant. Sometimes it guesses right. More often it misses — and the misses accumulate until the project stops responding to changes.

2.0 // SCOPE OF WORK

What's included in the specification

I write a complete technical specification that turns AI development from guesswork into execution. Document package:

ARCH

Architecture & Data

System structure, data models, module boundaries.

INV

Invariants

Rules the system is not allowed to break. Verifiable, with conditions.

GLOS

Glossary

Unified terms so the agent doesn't confuse entities between sessions.

AGNT

AI Agent Rules

What the agent may change, what is prohibited, how to verify its own work.

PLAN

Phase Plan

Sequence of work with acceptance criteria for each phase.

The methodology is open and published: ANSS Standard on GitHub. You can review the approach before paying.
