1.0 // WHO IT IS FOR

Who comes to the sessions

HR and recruiting: candidate screening, correspondence, meeting transcripts and notes.

Owners of small companies who want to automate repetitive tasks without ordering a system from a vendor.

2.0 // HOW IT WORKS

Working on the participant's task

  1. Free 30-minute call: the task, the tools available, how many sessions it may take.
  2. Before the session the participant sends a task description and sample materials. A plan is prepared from them.
  3. In the session the task is described together: goal, inputs, expected output, what to avoid. This becomes prompts or a specification for Claude Code.
  4. The participant carries out the steps on their own computer. The consultant guides, explains and corrects.
  5. After the session, a short summary: what works, what is left, what the next step is.

Payment for agreed time

The number of sessions depends on the task and is estimated on the free call. A simple task may take one session, a complex one several.

5.0 // FORMAT LIMITS

What this format does not include

This is not a course with a syllabus, slides and homework. Between sessions the solution is not built for the participant, and a finished automation is not promised. If a vendor needs to build a system, start with a specification. If the processes of a whole department need assessing first, see the audit. If you only need advice, without hands-on work, a consultation fits.
