OMS/DMS distribution management system

Distribution grid operator, 2011–2019. Project manager, client side.

1.0

The task

The grid management system was built on Telvent OMS/DMS (now Schneider Electric), developed in Novi Sad. Systems of this class help dispatchers run a distribution grid: see its state, locate faults and restore supply. The rollout started at the same pilot branch where the metering system had been tested earlier.

2.0

What was done

The project was run from the client's IT department, later from the department operating dispatch and process control systems and IT. On the client side: tender documentation and public procurement, contracts with the vendor and contractors, control of their execution, support up to commissioning. After commissioning: technical support contracts, reports and justifications for management prepared together with the head of the unit. The same department handled support contracts for high-voltage data collection devices and meters.

3.0

Result

The system was commissioned in 2014 and then maintained under technical support contracts.

4.0

What carries over today

The cost of a system does not end at commissioning: support, updates, hardware replacement and contracts follow. That is why choosing a solution includes the total cost of ownership over several years, and support is part of implementation from the start.
