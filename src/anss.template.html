ANSS Standard

An open standard for technical specifications in development with AI agents. Boundaries, invariants and acceptance criteria are written down before work starts, so the agent does not have to guess what is missing.

1.0 // PROBLEM

The problem it solves

Classic spec formats (IEEE 830, ISO/IEC 29148, GOST 34.602) were written for people: a person fills the gaps with domain knowledge. An AI agent fills them immediately and in its own way, using its training data. Most of the time that works. When it doesn't, code that was never supposed to exist has to be unwound by hand.

2.0 // STRUCTURE

How it works

Every section of a specification is tagged with a layer: what to build (for the client), how to build (for the developer), rules for the agent (the agent reads these first).

An invariant is written in four fields: what is forbidden, why, and how to check it. The check field is specific, and the agent tests its own output against it.

INV-001: No external npm packages
Cannot:  add require() of npm modules
Reason:  app must run without npm install
Check:   no node_modules imports in server.js

Three levels: Core for most projects (bots, integrations, automations, SaaS), Extended for security requirements and detailed testing, Enterprise for regulated industries.

3.0 // WHO IT'S FOR

Who it is for

For clients commissioning development without an engineering department of their own, solo developers and small teams, and companies automating processes with AI. In a large company, tickets, code review and CI provide the discipline. Here a single document takes their place.

4.0 // CONTENTS

What is in the repository

The standard in English and Russian. A Core-level template. A skill for Claude and Claude Code: writes a specification, converts an existing requirements document to ANSS and reviews a specification before development. Presets for CLAUDE.md, AGENTS.md and Cursor. Two examples from real projects.

5.0 // SETUP

How to set it up

Claude (claude.ai and the app). Download anss-skill.zip. Open claude.ai/customize/skills, click “+”, then “Create skill” and “Upload a skill”, and pick the archive. Code execution must be on (claude.ai/settings/capabilities).

Claude Code. Copy the skills/anss/ folder to ~/.claude/skills/anss/ (all projects) or .claude/skills/anss/ (one project).

Cursor. Put templates/anss.mdc in .cursor/rules/.

Codex, Copilot and other agents. templates/AGENTS.md in the project root.

Terminal commands are in the repository README.
