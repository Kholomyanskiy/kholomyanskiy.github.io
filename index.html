01
ANSS Standard
AI-Native System Specification Standard
↗ Open Source

Открытый стандарт написания технических спецификаций для AI-разработки. Решает проблему «агент делает технически правильно, но архитектурно неверно». Сократил итерации с 5–7 до 2–3 на реальных проектах.

  • Трёхслойная структура [D/E/A] — агент знает что читать первым
  • Инварианты — машиночитаемые ограничения с полем «Проверка»
  • Agent Review — агент аудирует ТЗ до написания кода. >3 проблем = стоп
  • Change Specification — явный список «что НЕ менять» при доработках
  • Работает с Claude Code, Cursor, Copilot

invariant: no_delete_transactions
verify: grep "DELETE" migrations/
[E] stack: FastAPI · PostgreSQL · Telegram

[A] agent_review: ✓ 0 issues — proceed

eSowa KPI Bot
KPI-бот для механиков автосервиса · Польша
● В продакшне

Telegram-бот, подключённый напрямую к базе данных eSowa. Каждый механик видит свою выработку за день и месяц прямо в Telegram. Установка офлайн за 3 шага — без IT-специалиста, работает на компьютере клиента.

  • Автозапуск через Windows Task Scheduler — поднимается сам после перезагрузки

ЛомбардПРО
Система управления сетью ломбардов
◎ Спецификация готова · переговоры

Комплексная система автоматизации для сети из 3 ломбардов. Покрывает полный операционный цикл — от инкассации изделий до аналитики для владельца. Разрабатывается по стандарту ANSS, задеплоена на Railway.

  • Telegram-бот для владельца: ежедневная сводка, алерты, подтверждение инкассаций кнопками
  • Веб-приложение для сотрудников: замена Excel, касса, скупка, инкассация с фото
  • Веб-дашборд: аналитика, движение изделий, отчёты в .xlsx
  • Целевые показатели по ТЗ: сверка кассы <3 мин (сейчас ~30), 100% трек инкассированных изделий
  • Деплой на Railway с auto-deploy из GitHub, фото в Supabase Storage

Городской AI-ассистент для жителей и туристов
◎ Концепт/MVP
